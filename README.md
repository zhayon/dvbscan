# dvbscan

Сканер DVB-C, DVB-T/T2 и DVB-S/S2 для Linux. Перебирает частоты, ловит захват
(lock) на тюнере, на каждом найденном мультиплексе читает PAT и SDT и печатает
список программ и готовый блок `dvb_card` для конфига Flussonic.

Работает напрямую через Linux DVB API (`/dev/dvb/adapterN`), зависимостей нет:
один файл на C.

## Сборка

Нужны компилятор C и заголовки ядра Linux (`linux/dvb/frontend.h`). В Debian и
Ubuntu это пакеты `build-essential` и `linux-libc-dev`.

```
make            # ./dvbscan
make static     # статический бинарник, удобно копировать на сервер
make install    # в /usr/local/bin, PREFIX и DESTDIR учитываются
```

На macOS заголовков `linux/dvb` нет, поэтому собирать нужно в Linux-контейнере.
Бинарник под x86_64-сервер:

```
docker run --rm --platform linux/amd64 -v "$PWD":/src -w /src gcc:14 make static
scp dvbscan server:/usr/local/bin/
```

## Перед запуском

Фронтенд должен быть свободен. Если на сервере крутится Flussonic, остановите
его (`systemctl stop flussonic`) или сканируйте адаптер, который он не занимает.
Сканер открывает `/dev/dvb/adapterN/frontendM` на запись и пишет в него.

## Использование

```
./dvbscan -a ADAPTER [-f FRONTEND] [-s SYSTEMS] [опции]
```

Если `-s` не задан, сканер спрашивает у фронтенда, что тот умеет, и пробует все
поддерживаемые системы. Комбинированным тюнерам (например, C/T/T2) нужно явно
указать семейство: за один запуск сканируется одно семейство.

| `-s`    | что пробуется на каждой частоте |
|---------|---------------------------------|
| `c`     | DVB-C (Annex A)                 |
| `t`     | DVB-T, затем DVB-T2             |
| `s`     | DVB-S, затем DVB-S2             |

Системы можно перечислять и по одной, через запятую: `dvbt2`, `dvbs2`,
`dvbt,dvbt2`.

### Кабель, DVB-C

```
./dvbscan -a 0 -s c
```

По умолчанию проходит сетку 114–858 МГц с шагом 8 МГц. На каждой частоте
пробуются символьные скорости 6875, 6900, 6952 и 6111 кСимв/с и модуляции
`qam_auto`, `qam256`, `qam64`. Свои значения задаются через `--sr 6875,6900` и
`--mod qam256`.

### Эфир, DVB-T/T2

```
./dvbscan -a 0 -s t                          # UHF, каналы 21–69, полоса 8 МГц
./dvbscan -a 0 -s t --from 177.5 --to 226.5 --step 7 --bandwidth 7   # VHF III, 7 МГц
./dvbscan -a 0 -s dvbt2 --plp 1              # только T2, конкретный PLP
```

По умолчанию сетка 474–858 МГц с шагом 8 МГц, полоса 8 МГц. Частоты можно
задавать дробными мегагерцами. Без `--plp` фильтр PLP не ставится, и драйвер
берёт первый PLP. Перечислить PLP через стандартный API ядра нельзя: если на
частоте их несколько, нужный придётся указать вручную.

### Спутник, DVB-S/S2

```
./dvbscan -a 0 -s s                                   # весь Ku 10700–12750, H и V
./dvbscan -a 0 -s s --from 11700 --to 12100 --pol v   # кусок диапазона
./dvbscan -a 0 -s s --lnb 10750                       # конвертер с одним гетеродином
./dvbscan -a 0 -s s --diseqc 2                        # второй вход DiSEqC-коммутатора
```

Конвертер по умолчанию универсальный: гетеродины 9750 и 10600 МГц, переключение
диапазона на 11700 МГц тоном 22 кГц. Полярность переключается питанием LNB:
13 В для V/R, 18 В для H/L. Варианты `--lnb`:

- `universal` — значение по умолчанию;
- `10750` — один гетеродин, тон всегда выключен;
- `9750,10600,11700` — свой универсальный конвертер: нижний гетеродин, верхний
  гетеродин и частота переключения.

На каждой точке сетки пробуются скорости 27500, 30000 и 22000 кСимв/с
(`--sr`). Для DVB-S2 по умолчанию выставляется модуляция `qpsk`, как это сделает
и Flussonic без явной `modulation`. Большинство демодуляторов определяет
QPSK/8PSK сами, но если драйвер требует точной модуляции, передайте
`--mod qpsk,psk8`.

Демодулятор ловит транспондер и при небольшой расстройке. После захвата сканер
берёт у драйвера фактическую частоту, модуляцию и roll-off, а соседние точки
сетки, которые попадают в полосу найденного транспондера, пропускает.

Полный проход спутника по сетке долгий: до 40 минут, если сигнала нет совсем.
Если список транспондеров известен (с сайтов вроде lyngsat или kingofsat), быстрее
отсканировать по нему, см. «Сканирование по списку».

### Сканирование по списку

`--list FILE` вместо сетки берёт частоты из файла. В файле учитываются строки,
где есть `freq=`; строки, начинающиеся с `#`, пропускаются. Параметры пишутся
как `ключ=значение`:

| ключ      | значение                                                       |
|-----------|----------------------------------------------------------------|
| `system`  | `dvbca` (или `dvbc`), `dvbt`, `dvbt2`, `dvbs`, `dvbs2`         |
| `freq`    | МГц; значения от 1 000 000 считаются герцами                   |
| `sr`      | кСимв/с                                                        |
| `mod`     | `qam64`, `qam256`, `qam_auto`, `qpsk`, `psk8`, …               |
| `pol`     | `h`, `v`, `l`, `r`                                             |
| `bw`      | полоса DVB-T/T2, МГц                                           |
| `plp`     | PLP DVB-T2                                                     |

Всё, что не указано, берётся из опций командной строки и умолчаний. Если нет
`system=`, используется `-s`. Пример:

```
system=dvbs2 freq=11766 pol=h sr=27500
system=dvbs  freq=12226 pol=v sr=27500
freq=12380 pol=v sr=27500
```

Лог прошлого сканирования — тоже подходящий список: строки `LOCK` в нём записаны
в этом же формате. Перепроверить найденное, например с более долгим сбором
программ, можно так:

```
./dvbscan -a 0 --list dvbscan_dvbs_a0.log --psi-ms 8000
```

Старые логи `dvbc_scan` из `contrib` Flussonic тоже читаются (`--from-log` —
синоним `--list`).

### Все опции

```
-a, --adapter N      /dev/dvb/adapterN (0)
-f, --frontend N     frontendN (0)
    --demux N        demuxN и dvrN (по умолчанию номер фронтенда, если такой есть, иначе 0)
-s, --system LIST    c, t, s, dvbc, dvbt, dvbt2, dvbs, dvbs2 через запятую
    --from MHZ       начало сетки  (dvbc 114, dvbt 474, dvbs 10700)
    --to MHZ         конец сетки   (dvbc 858, dvbt 858, dvbs 12750)
    --step MHZ       шаг сетки     (dvbc 8, dvbt 8, dvbs 6)
    --sr LIST        символьные скорости, кСимв/с
    --mod LIST       модуляции
    --bandwidth MHZ  полоса DVB-T/T2: 1.712, 5, 6, 7, 8, 10 (8)
    --plp N          PLP DVB-T2
    --pol LIST       поляризации спутника (h,v)
    --lnb TYPE       universal, LOF или LO,HI,SWITCH
    --diseqc N       порт DiSEqC 1.0, 1..4
    --wait MS        сколько ждать захвата на одну попытку (dvbc 400, dvbt 1200, dvbs 600)
    --psi-ms MS      сколько собирать PAT/SDT на найденном мультиплексе (3000)
    --no-psi         только искать захват, программы не читать
    --list FILE      частоты из файла вместо сетки
-o, --output FILE    куда писать лог
```

Если тюнер медленно захватывает сигнал (бывает на DVB-T2 и на слабом спутниковом
сигнале), увеличьте `--wait`. Если в списке не хватает названий программ,
увеличьте `--psi-ms`: SDT на больших мультиплексах приходит не сразу.

Ctrl-C останавливает сканирование, и сканер выводит то, что успел найти.
Повторный Ctrl-C завершает его сразу.

## Результат

Прогресс идёт в stderr, итог — в stdout и в лог `dvbscan_<семейство>_aN.log`
в текущем каталоге (`dvbscan_dvbs_a0.log`; для `-f 1` — `dvbscan_dvbs_a0f1.log`;
для `--list` — с суффиксом `_rescan`).

На каждый найденный транспондер выводится строка параметров с уровнем сигнала
(если драйвер отдаёт статистику DVBv5), список программ из SDT (с провайдером и
пометкой `scrambled`) и блок для `flussonic.conf`:

```
LOCK system=dvbs2 freq=11766 pol=h sr=27500 mod=psk8 rolloff=20 cnr=12.3dB signal=-45.6dBm  programs=12 named=12
  program 1     Sat One HD  [Provider]
  ...
dvb_card s0_11766h {
  adapter 0;
  frontend 0;
  system dvbs2;
  frequency 11766;
  symbol_rate 27500;
  polarization h;
  modulation psk8;
  rolloff 20;
}
```

Единицы в блоке такие, каких ждёт Flussonic. Для кабеля и эфира `frequency`
указывается в герцах, `bandwidth` — в герцах. Для спутника `frequency`
указывается в мегагерцах, `symbol_rate` — в кСимв/с. `int_freq` и `high_band`
появляются только для неуниверсального LNB: универсальный Flussonic считает сам.

Названия программ, которых нет в SDT своего мультиплекса, сканер добирает из
SDT other соседних мультиплексов.

## Ограничения

- DiSEqC сканер переключает сам, но в блоке `dvb_card` порт не записывается:
  у `dvb_card` с `hw dvb` такого параметра нет.
- Для C-диапазона (гетеродин выше частоты, например `--lnb 5150`) сканер
  настраивается правильно, но Flussonic вычисляет ПЧ как `frequency - int_freq`.
  Такой блок `dvb_card` нужно проверить вручную.
- Multistream DVB-S2 (ISI), DVB-C Annex B/C, ATSC и ISDB-T не поддерживаются.
- Это перебор частот, а не аппаратный blind scan. Транспондеры с символьной
  скоростью не из списка `--sr` будут пропущены.

## Проверка

`make check` собирает LD_PRELOAD-заглушку фронтенда (`tests/fakedvb.c`) и
сканирует ей кабель, эфир и спутник, сверяя вывод. Нужен Linux; на macOS:

```
docker run --rm -v "$PWD":/src -w /src gcc:14 make check
```
